# 灵凌同学 · 爆款复刻技能套件

作者：**李加炜**｜品牌：**灵凌同学**｜[官网](https://xhs.typoai.xin)

把一套参考图文拆成可复用的玩法，再搭建可独立运行的本地创作工作台。当前为公开试用版，非完整跨客户端认证版本。

## 三个技能

| 技能 | 用途 | 版本 |
|---|---|---|
| `remake-studio` | 总入口，识别阶段、检查能力、衔接两个子技能 | 0.1.0 |
| `flow-spec-builder` | 拆解参考图文、打磨并验证提示词、交付完整流程 | 0.5.2-codex.7-draft |
| `remake-workbench-builder` | 搭建本地工作台、增加玩法、维护固定规则 | 0.2.1 |

## 安装与开始

先读 [安装与使用说明](先看这里-安装与使用.md)。可下载本仓库 ZIP，或让 Agent 克隆仓库，再发送：

> 请阅读此仓库的安装与使用说明，把 skills 下的三个技能安装到当前 Agent 支持的位置。已有同名技能先检查差异并备份，不合并新旧文件。保留其他技能以及我的工作台、玩法、作品和模型配置。完成后检查三个技能是否可用。

安装后，从总入口开始：

> 使用 $remake-studio，帮我把这套参考图文拆成可复用玩法，并放进我的本地工作台。先检查读图、文字和生图能力，缺少连接时引导我配置。

技能不是双击运行的软件，也不附送模型额度。工作台日常运行无需打开 Agent，但需要独立的文字和图片 API 连接；首次搭建需要 Python 3.10 或以上环境。
