# 灵凌同学 · 爆款复刻技能套件

作者：**李加炜**｜品牌：**灵凌同学**｜[官网](https://xhs.typoai.xin)

把一套参考图文拆成可复用的玩法，再搭建可独立运行的本地创作工作台。当前为公开试用版，非完整跨客户端认证版本。

## 四个技能

| 技能 | 用途 | 版本 |
|---|---|---|
| `remake-studio` | 总入口，识别阶段、检查能力、衔接两个子技能 | 0.1.1 |
| `flow-spec-builder` | 拆解参考图文、打磨并验证提示词、交付完整流程 | 0.5.2-codex.7-draft |
| `remake-workbench-builder` | 搭建本地工作台、增加玩法、维护固定规则 | 0.2.1 |

| `remake-suite-updater` | 检查稳定版、更新套件、备份与回滚 | 0.1.0 |

## 安装与开始

先读 [安装与使用说明](先看这里-安装与使用.md)。可下载本仓库 ZIP，或让 Agent 克隆仓库，再发送：

> 请阅读此仓库的安装与使用说明，把 skills 下的四个技能安装到当前 Agent 支持的位置。已有同名技能先检查差异并备份，不合并新旧文件。保留其他技能以及我的工作台、玩法、作品和模型配置。完成后检查四个技能是否可用。

安装后，从总入口开始：

> 使用 $remake-studio，帮我把这套参考图文拆成可复用玩法，并放进我的本地工作台。先检查读图、文字和生图能力，缺少连接时引导我配置。

技能不是双击运行的软件，也不附送模型额度。工作台日常运行无需打开 Agent，但需要独立的文字和图片 API 连接；首次搭建需要 Python 3.10 或以上环境。

## 更新状态

安装更新技能后，对 Agent 说：

> 使用 $remake-suite-updater，把爆款复刻套件更新到最新稳定版，保留我的工作台、玩法、作品和模型配置。

尚未安装更新技能时，把 [首次安装与更新入口](INSTALL.md) 的链接交给 Agent。无需 GitHub 账号或 Git，需要 Python 3.10+。程序检查官方 stable 分支，校验、备份并更新四个技能；旧安装或本地修改有冲突时先说明再处理。更新失败可恢复，已有工作台另行迁移。客户端可能需要刷新或新开会话。

见 [更新记录](CHANGELOG.md)。main 为开发分支，stable 为已验证交付分支。

## 验证范围
