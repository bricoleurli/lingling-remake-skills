# 爆款复刻工作室

作者：李加炜｜品牌：灵凌同学｜官网：https://xhs.typoai.xin 。来源见 [作者说明](references/AUTHORS.md)。

总入口只负责识别阶段、准备生成能力和衔接交付，不重写两个子技能的方法，不要求另开对话或创建子Agent。子技能仍能独立使用。

1. 找到项目、已有case.json、最新交付与工作台，读取用户决定。按 [阶段路由](references/routing.md) 选择下一步，不把已有拆解重做一遍。
2. 必读 [模型能力与真实测试](references/model-access.md)。检查当前可用读图/文字/生图工具以及目标工作台API；缺项主动问，按服务商官方文档配置。用户暂缓配置时继续不依赖模型的部分。
3. 定位子技能：先使用本套件同级目录的SKILL.md；独立安装时查当前可用技能清单及对应已安装文件。读到实际文件后才执行，不猜路径或虚构已调用。缺少技能时告诉用户缺哪一个并提供安装位置；总入口不暗中全局安装。
4. 参考图到完整交付：读取flow-spec-builder/SKILL.md并遵循八步和已有确认点，保留原提示词与验证证据。不得因总入口存在跳过用户验收。
5. 完整交付到工具：先核对用户已经授权做工作台，再读取remake-workbench-builder/SKILL.md；创建、追加或更新现有工作台。只要求拆解时在拆解交付处结束，不自动扩大为建站。
6. 交接引用交付路径、版本、用户日常输入决定、固定项、已测试/待测试范围和model-access-status.json；不复制Key。内置样张不能作为独立API的验证结果。
7. 保存项目进度与下一步，分开说明文件完成、程序可运行、真实模型成功和用户认可。完成用户当前授权的范围，不为调用完所有技能而多做工作。

以后新增功能按 [扩展规则](references/routing.md) 注册。总入口、共同规则和子技能分层维护；共同文件通过套件脚本同步，独立副本须校验一致。

路由检查样例在 `evals/`，维护证据在 `reports/`；启发式检查不代表跨模型实测。
