# 主动询问并协助配置模型连接

共同能力判断、询问、文档查阅、授权与实测标准统一见 [model-access.md](model-access.md)，不要在本文件另写一套不同规则。

本技能落地位置：工作台“设置 → 模型连接”。文字/图片服务可以分开填写Base URL、API Key和模型名。已有连接沿用；用户已说稍后填写，不重复催问。先读本项目的非敏感配置状态，不读取其他项目Key。

本机保存位置为data/settings.json，不是产品作者服务器，也不是仅内存模式。密钥不能出现在Skill、报告、截图和交付ZIP中。

取得服务商信息后必须按共同规则查其官方文档，并记录文字、纯文字生图、参考图生图是否匹配底座协议。当前实现仅支持chat/completions与images/generations、images/edits；非兼容供应商需要适配器、模拟检查和真实请求分别验证。禁止靠省略参考图或改变玩法静默适配。

第一技能可能用内置工具或Agent文字完成样张。第二技能必须用工作台实际进程重测文字和图片端点，才能标注工作台真实可用。配置缺失仍可完成程序、样张展示与模拟验证。
